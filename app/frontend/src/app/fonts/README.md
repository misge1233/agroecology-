# Self-hosted fonts

`NotoSansEthiopic-ethiopic.woff2` — Noto Sans Ethiopic, variable weight 400–600, **ethiopic**
subset, downloaded from Google Fonts (SIL Open Font License 1.1) on 2026-10-26 and served
through `next/font/local` (U1). It is self-hosted instead of `next/font/google` because
Turbopack's Google-font loader rejects this family ("next/font/google queries have exactly
one entry"), which broke `next dev` on every page.

Source: `https://fonts.gstatic.com/s/notosansethiopic/v50/7cHAv50vjIepfJVOZZgcpQ5B9FBTH9KGNfhSTgtoow1KVnIv4gckut2Q.woff2`
